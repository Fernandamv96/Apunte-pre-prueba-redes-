## 📖 Sobre el proyecto

Este repositorio contiene un apunte en HTML pensado como material de repaso rápido sobre **direccionamiento IP**: conceptos clave, ejemplos y notas útiles para preparar una evaluación de redes.

## 📂 Estructura


## 🚀 Cómo usarlo

**Opción 1 — Online**
Abre directamente la [demo en Vercel](https://apunte-pre-prueba-redes.vercel.app).

**Opción 2 — Local**
```bash
git clone https://github.com/Fernandamv96/Apunte-pre-prueba-redes-.git
cd Apunte-pre-prueba-redes-
```
Abre `index.html` en tu navegador.

## 🛠️ Despliegue

El proyecto se despliega automáticamente con **Vercel** en cada push a la rama `main`.

## 🔒 Calidad y seguridad

- CI en cada push y PR: `html-validate`, además de CodeQL, Dependabot y gitleaks en pre-commit.
- Para reportar vulnerabilidades, mira [SECURITY.md](SECURITY.md).
