2. Conceptos Clave (Glosario)

Dirección IP (IPv4)

Número de 32 bits dividido en 4 octetos (grupos de 8 bits) separados por puntos. Cada octeto va de 0 a 255. Ejemplo: 192.168.1.10

Máscara de Subred

Número de 32 bits que indica qué parte de la IP es red (bits en 1) y qué parte es host (bits en 0). Ejemplo: 255.255.255.0

CIDR (Notación /n)

Forma compacta de expresar la máscara. El número indica cuántos bits son de red. Ejemplo: /24 = 255.255.255.0 (24 unos)

Dirección de Red

Primera IP del bloque. Todos los bits de host en 0. No se puede asignar a dispositivos. Identifica la subred.

Dirección de Broadcast

Última IP del bloque. Todos los bits de host en 1. No se puede asignar a dispositivos. Permite enviar mensajes a todos los hosts.

Hosts Válidos

IPs entre la dirección de red y el broadcast. Fórmula: 2ⁿ − 2, donde n = bits de host.

FLSM

Fixed Length Subnet Mask. Todas las subredes tienen el mismo tamaño e idéntica máscara. Fácil de calcular pero desperdicia IPs.

VLSM

Variable Length Subnet Mask. Cada subred tiene un tamaño diferente según necesidad. Eficiente pero más complejo. Siempre ordenar de mayor a menor.

Subnetting (Subneteo)

Técnica de dividir una red grande en subredes más pequeñas. Se "toman" bits de la parte de host para crear más redes.

Salto (Incremento)

Diferencia entre el inicio de cada subred. Se calcula como: 256 − valor decimal del último octeto de la máscara.

3. Explicaciones Simplificadas

📱 ¿Qué es una IP? — Desde Cero

Una dirección IP es como el número de teléfono de tu computadora. Así como cada teléfono tiene un número único para recibir llamadas, cada dispositivo en red tiene una IP para comunicarse. La diferencia: las IPs públicas no se repiten en todo el mundo (como un número de pasaporte), pero las IPs privadas sí pueden repetirse en distintas redes hogareñas.

🏠 Clases de IP — La Analogía del Edificio

Imagina la IP como una dirección postal: "País . Ciudad . Calle . Número"
• Clase A = Ciudad gigante: 1 número para el país, 3 para la dirección específica → muchos vecinos (16 millones de hosts)
• Clase B = Ciudad mediana: 2 números para el país/ciudad, 2 para la dirección → capacidad media (65.534 hosts)
• Clase C = Ciudad pequeña: 3 números para el país/ciudad/calle, 1 para la casa → pocos vecinos (254 hosts)

🔢 Conversiones Numéricas — Paso a Paso

Binario → Decimal

Multiplica cada bit por su potencia de 2 (de derecha a izquierda) y suma.

10101010 → 128+0+32+0+8+0+2+0 = 170
11000000 → 128+64+0+0+0+0+0+0 = 192
11111111 → 128+64+32+16+8+4+2+1 = 255
Decimal → Binario

Divide sucesivamente entre 2, anota el residuo. Lee de abajo hacia arriba.

25 ÷ 2 = 12 (r=1) → 12 ÷ 2 = 6 (r=0) → 6 ÷ 2 = 3 (r=0) → 3 ÷ 2 = 1 (r=1) → 1 ÷ 2 = 0 (r=1)
Leído al revés: 11001 → con 8 bits: 00011001
Binario → Hexadecimal

Agrupa de 4 en 4 bits desde la derecha, convierte cada grupo.

10101111 → 1010 | 1111 → A | F = AF
Tabla: 0000=0, 0001=1 … 1001=9, 1010=A, 1011=B, 1100=C, 1101=D, 1110=E, 1111=F

🔀 ¿Qué es la Máscara? — La Analogía del Código Postal

Imagina que tienes la dirección "192.168.5.23" y la máscara "255.255.255.0". La máscara te dice: "los primeros 3 grupos (192.168.5) son el BARRIO (red), y el último número (23) es el NÚMERO DE CASA (host)". Todos los que viven en el mismo barrio comparten los 3 primeros números.

La máscara en binario: los 1s identifican la parte de red, los 0s identifican la parte de host.

255.255.255.0 → 11111111.11111111.11111111.00000000 → /24

✂️ Subnetting — La Analogía del Terreno

Tienes un terreno grande (red 192.168.1.0/24 = 256 direcciones). En lugar de tenerlo sin dividir, decides construir 4 casas (subredes) con sus propios cercos. Cada casa tiene su propio rango de números de cuartos (hosts). Para dividirlo en 4, necesitas "tomar" 2 bits del espacio de host (2² = 4 parcelas), lo que cambia tu máscara de /24 a /26.

4. Puntos Críticos para la Prueba

🚨 FÓRMULAS QUE NO PUEDES OLVIDAR:
Hosts = 2ⁿ − 2
(n = bits de host)
Subredes = 2ⁿ
(n = bits prestados)
Salto = 256 − máscara decimal
(del último octeto)
Nueva máscara = /X + n bits
(n = bits prestados)

📌 Pasos del Subnetting FLSM — Procedimiento Exacto

1
Identificar la red base Ej: 192.168.1.0/24 con máscara 255.255.255.0
2
Calcular bits necesarios ¿Cuántas subredes necesitas? Busca 2ⁿ ≥ N subredes. Ej: 4 subredes → 2² = 4 → n = 2 bits
3
Calcular nueva máscara /24 + 2 = /26 → 255.255.255.192
4
Calcular salto 256 − 192 = 64 → Las subredes avanzan de 64 en 64
5
Asignar rangos y completar tabla Red, Primer host, Último host, Broadcast
6
Calcular hosts por subred 32 − 26 = 6 bits de host → 2⁶ − 2 = 62 hosts

📌 Pasos del Subnetting VLSM — Procedimiento Exacto

1
Ordenar de MAYOR a MENOR número de hosts Siempre empezar por la subred más grande
2
Para cada subred: calcular máscara usando 2ⁿ − 2 ≥ hosts requeridos Busca el n mínimo que satisfaga la cantidad de hosts
3
Asignar rangos consecutivos sin solapamiento Cada subred empieza donde termina la anterior (broadcast + 1)

6. Errores Comunes en Pruebas

Error 1 — Olvidar restar 2 en la fórmula de hosts
Muchos calculan 2ⁿ y no 2ⁿ−2. Recuerda: siempre se restan la dirección de red y la de broadcast. Si una /26 tiene 6 bits de host → 2⁶ = 64 total, pero solo 62 hosts útiles.
Error 2 — En VLSM, no ordenar de mayor a menor
Si empiezas por la subred pequeña, te quedarás sin espacio para la grande. Siempre: primero la subred con más hosts, luego las siguientes.
Error 3 — Confundir la dirección de red con el primer host
Si la red es 192.168.1.64/26, el PRIMER HOST es 192.168.1.65, NO 192.168.1.64. La .64 es la dirección de red (reservada).
Error 4 — Calcular mal el salto
El salto NO es el valor de la máscara, es 256 menos el valor del último octeto. Para /26 (máscara 192): 256 − 192 = 64, no 192.
Error 5 — Determinar mal la clase de una IP
La clase se determina por el primer octeto:
1-126 = Clase A | 128-191 = Clase B | 192-223 = Clase C
¡Ojo! El 127 está reservado (loopback, no es clase A ni B).
Error 6 — Confundir bits de host con bits de red para la máscara
Si tienes /26 → 32 bits totales − 26 bits de red = 6 bits de HOST. Esos 6 bits van en la fórmula 2⁶ − 2. No uses 26.
Error 7 — En FLSM: la nueva máscara se SUMA, no multiplica
Si la red base es /24 y necesitas 3 bits → /24 + 3 = /27. No es /24 × 3.
Error 8 — Pensar que el broadcast es la red de la siguiente subred
En la red 192.168.1.0/26, el broadcast es 192.168.1.63 (el último del bloque), NO 192.168.1.64 (esa es la próxima red).

8. Preguntas Tipo Prueba

Haz clic en cada opción para ver si es correcta o incorrecta. Luego usa el botón para ver la explicación.
1. ¿Cuántos hosts útiles tiene una red con máscara /26?
  • a) 64
  • b) 66
  • c) 62
  • d) 30
/26 → 32 − 26 = 6 bits de host → 2⁶ − 2 = 64 − 2 = 62 hosts útiles. Se restan 2 porque la dirección de red y la de broadcast no se pueden asignar a dispositivos.
2. La dirección IP 172.18.5.10, ¿de qué clase es?
  • a) Clase A
  • b) Clase B
  • c) Clase C
  • d) Clase D
El primer octeto es 172. Las IPs de Clase B van del 128 al 191. Como 172 está en ese rango → Clase B. Máscara por defecto: 255.255.0.0 (/16).
3. ¿Cuál es el salto (incremento) para una red /25?
  • a) 64
  • b) 128
  • c) 192
  • d) 254
/25 → máscara 255.255.255.128 → Salto = 256 − 128 = 128. Las subredes serán: .0 y .128.
4. En VLSM, si necesitas 30 hosts, ¿qué máscara usas?
  • a) /28 (14 hosts)
  • b) /26 (62 hosts)
  • c) /27 (30 hosts)
  • d) /25 (126 hosts)
Busco 2ⁿ − 2 ≥ 30. Con n=5: 2⁵ − 2 = 30 ≥ 30 ✅ → máscara /27 (255.255.255.224). El /28 solo da 14 hosts (insuficiente) y el /26 da 62 (malgasta IPs).
5. Tienes la red 10.0.0.0/24 y necesitas 8 subredes. ¿Cuál es la nueva máscara?
  • a) /25
  • b) /26
  • c) /27
  • d) /28
2ⁿ ≥ 8 → n = 3 bits. Nueva máscara: /24 + 3 = /27. Esto da 8 subredes con 30 hosts cada una.
6. ¿Cuál es la diferencia principal entre FLSM y VLSM?
  • a) FLSM usa IPv6 y VLSM usa IPv4
  • b) FLSM crea subredes del mismo tamaño; VLSM crea subredes de distintos tamaños
  • c) VLSM es más fácil de calcular que FLSM
  • d) FLSM es más eficiente en uso de IPs
FLSM (Fixed Length Subnet Mask) → todas las subredes iguales, fácil pero desperdicia IPs. VLSM (Variable Length Subnet Mask) → subredes de tamaño variable, eficiente pero más complejo.
